❓ Hướng dẫn sử dụng PrintMerge

📝 Thiệp mời
  • Upload ảnh mẫu PNG/JPG (từ PSD, Canva…)
  • Upload file Excel chứa danh sách khách
  • Nhấn ＋ Thêm trường, gõ {Tên_cột} hoặc click chip cột
  • Nhấn 🎯 Chọn vị trí rồi click lên ảnh để đặt tọa độ
  • Dùng mũi tên ↑↓←→ để tinh chỉnh từng pixel
  • Chỉnh font, cỡ chữ, màu sắc theo ý muốn
  • Nhấn 📂 Xuất thư mục hoặc 🗜️ ZIP
🏆 Giấy chứng nhận
  • Làm tương tự tab Thiệp mời
  • Thêm trường ảnh học sinh: tên file ảnh phải khớp cột Excel
  • VD: cột Excel ghi NguyenVanA → file ảnh đặt tên NguyenVanA.jpg
  • Upload nhiều ảnh cùng lúc ở mục Ảnh học sinh
  • Chọn Fill mode: Cover (cắt khít) / Contain / Stretch
  • Tích Hình tròn để bo tròn ảnh thẻ
📄 PDF Form
  • Upload file PDF mẫu (phiếu, biểu mẫu…)
  • Upload ảnh thẻ 3×4, 4×6 (tuỳ chọn), kéo vào đúng ô
  • Thêm vùng che trắng để xoá nội dung sai rồi ghi đè
  • Nhấn ＋ Thêm trường, nhập nội dung trực tiếp
  • Dùng ↑↓←→ và chọn bước 1/5/10/50px để căn chỉnh
  • Nhấn 📄 Xuất PDF để tải file hoàn chỉnh
Mẹo nhanh
  • Phím mũi tên ← → trên bàn phím: chuyển trang xem trước
  • Bước di chuyển 1px để căn chỉnh pixel-perfect
  • Kéo thả file trực tiếp vào vùng upload thay vì click
  • Font bằng khen: Playfair Display, Lora, EB Garamond
  • Tên file xuất: dùng {Cột} để tạo tên riêng mỗi người
  • Bỏ dấu tiếng Việt trong tên file để tránh lỗi Windows
  • Nút ▲ thu gọn trường đã cài để thêm trường mới thuận tay
  • Trường mới tự kế thừa font, màu, cỡ chữ từ trường trước
📊 Cấu trúc file Excel mẫu
  • Dòng đầu là tiêu đề cột (tên cột = tên dùng trong {Tên_cột})
  • Hỗ trợ định dạng: .xlsx .xls .csv
  • Cột __EMPTY là cột trống trong Excel — bỏ qua hoặc xoá đi
  • Tên cột có khoảng trắng thừa vẫn hoạt động bình thường
